# Worked example: the F3 Insights brand

The shape a house brand takes, filled in. Replace these values with the owner's own brand when the caller or the rules file supplies one.

## Colors

| Name | Hex | RGB | Role |
|------|-----|-----|------|
| NAVY | `#1E3A6E` | (30, 58, 110) | Primary: headers, key callouts, primary buttons |
| BRONZE | `#A67C52` | (166, 124, 82) | The single accent, one or two elements per slide |
| BRONZE_LIGHT | `#B88B5E` | (184, 139, 94) | Hover, ring, lighter accent |
| GRAY | `#4B5563` | (75, 85, 99) | Body text on light backgrounds, muted secondary elements |
| WHITE | `#FFFFFF` | (255, 255, 255) | Background, inverse text |

## Type

| Use | Font |
|-----|------|
| Body and headings | Inter |
| Code and monospace | Consolas |

## Where the tokens live

The HTML deck kit in the `writing-seminar-builder` skill defines its own CSS tokens from the brand guide. When the brand changes, change the palette here and the deck kit's tokens together, so the two do not drift.
