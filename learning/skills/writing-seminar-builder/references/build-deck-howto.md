# Build Deck: How To

Step 4 of the workflow turns the locked Step-3 markdown outline into three concrete artifacts:

1. A per-seminar `build_deck.py` script that uses the skill's helpers
2. The resulting `.pptx` with speaker scripts embedded as PowerPoint notes
3. A flowing read-aloud `<seminar-slug>-transcript.md`

This reference is the procedure. Read `deck-styling.md` first for palette and layout choices.

---

## Output location and naming

Pick a kebab-case slug for the seminar (e.g., `finance-close-ai`, `support-triage-quickstart`). Create everything under a folder of that name in the current working directory:

```
<cwd>/<seminar-slug>/
├── build_deck.py
├── <seminar-slug>.pptx          # generated by running build_deck.py
└── <seminar-slug>-transcript.md
```

---

## Anatomy of `build_deck.py`

The script is plain Python that imports the skill's `deckbuilder` helpers and constructs slides in order. Use this scaffold:

```python
"""Build the <seminar title> deck.

Regenerate with: python build_deck.py
"""

from __future__ import annotations
import sys
from pathlib import Path

# Add the skill's scripts/ folder to sys.path so we can import deckbuilder.
# Point this at wherever the writing-seminar-builder skill is installed.
SKILL_SCRIPTS = Path("<path-to-writing-seminar-builder>") / "scripts"
sys.path.insert(0, str(SKILL_SCRIPTS))

from deckbuilder import (
    new_presentation, add_blank_slide,
    add_rect, add_text, add_bullets, add_code,
    add_chrome, slide_title, set_notes,
    NAVY, BRONZE, BRONZE_LIGHT, GRAY, LIGHT_GRAY, BORDER_GRAY,
    WHITE, ACCENT_RED, ACCENT_GREEN, ORANGE,
    TITLE_FONT, BODY_FONT, CODE_FONT,
    SLIDE_W, SLIDE_H, MARGIN,
)
from pptx.util import Inches, Pt
from pptx.enum.text import PP_ALIGN, MSO_ANCHOR

TOTAL = 12                                       # adjust to actual slide count
SECTION = "<Seminar series section name>"        # appears in footer chrome


def slide_01_outcome_promise(prs):
    s = add_blank_slide(prs)
    # Title slide: full-bleed NAVY band with bronze accent stripe
    add_rect(s, Inches(0), Inches(2.6), SLIDE_W, Inches(2.4), NAVY)
    add_rect(s, Inches(0), Inches(5.0), SLIDE_W, Inches(0.15), BRONZE)
    add_text(s, "<Outcome-promise title>",
             Inches(0.8), Inches(2.9), SLIDE_W - Inches(1.6), Inches(1),
             font=TITLE_FONT, size=44, bold=True, color=WHITE)
    add_text(s, "<Business-result subtitle>",
             Inches(0.8), Inches(3.9), SLIDE_W - Inches(1.6), Inches(0.6),
             size=22, italic=True, color=BRONZE)
    set_notes(s, """<the 60–120s speaker script from the Step-3 outline goes here>""")


def slide_02_assumptions(prs):
    s = add_blank_slide(prs)
    slide_title(s, "<Where we're assuming you are today>", "<Subtitle if any>")
    add_bullets(s,
        [
            ("<Platform stack>", "<one-line elaboration>"),
            ("<Data access>", "<one-line elaboration>"),
            ("<Organizational readiness>", "<one-line elaboration>"),
            ("<Skill floor>", "<one-line elaboration>"),
        ],
        MARGIN, Inches(2.1), SLIDE_W - 2 * MARGIN, Inches(4.5), size=20)
    add_chrome(s, 2, TOTAL, SECTION)
    set_notes(s, """<60–120s script>""")


# ... slide_03 through slide_N-1: teaching slides
# ... slide_N: closing offer


def main():
    prs = new_presentation()
    slide_01_outcome_promise(prs)
    slide_02_assumptions(prs)
    # ... call each slide function in order
    out = Path(__file__).parent / "<seminar-slug>.pptx"
    prs.save(out)
    print(f"Wrote {out}")


if __name__ == "__main__":
    main()
```

## Mapping the outline to layouts

Use the slide-type catalog in `deck-styling.md`. Rule of thumb:

- **Slide 1** → title-slide pattern (full-bleed NAVY band, no chrome)
- **Slide 2** → bullet slide with bronze gatekeeping line at the bottom
- **Teaching slides** → whatever the "Visual concept" field of the outline calls for: bullets, two-column split, three-column cards, stepped flow, or table
- **Closing offer slide(s)** → three horizontal `add_rect` cards for the tier menu, with a single-line CTA below

If a slide's visual concept doesn't fit any cataloged layout, compose it from the primitives (`add_rect` + `add_text` + `add_bullets`) rather than forcing a near-miss.

---

## Always do these on every non-title slide

1. **Call `set_notes(s, script)`** with the 60–120s speaker script from the outline. This is the entire reason we're using python-pptx: the script must land in the notes pane.
2. **Call `add_chrome(s, slide_num, TOTAL, SECTION)`** so the bronze top bar and slide-number footer stay consistent.
3. **Keep within `MARGIN`** on the left and right unless you're intentionally bleeding to the edge (title slide bands, full-width separators).

## The transcript file

Alongside the .pptx, write `<seminar-slug>-transcript.md` with this structure:

```markdown
# <Seminar Title>: Speaker Transcript

A read-aloud transcript of the full seminar in delivery order.
Each section is the speaker script for one slide.

---

## Slide 1: <slide title>

<the full 60–120s script, exactly as embedded in the .pptx notes pane>

---

## Slide 2: <slide title>

<script>

---

<continue for every slide>
```

This file is for rehearsal, captions, and repurposing (LinkedIn posts, blog excerpts, video subtitles). The text should match what's in the .pptx notes pane verbatim. If the user edits the transcript, they should be able to re-paste the updated scripts into `set_notes()` calls and rerun `build_deck.py`.

---

## Running the script

After writing `build_deck.py` and the transcript:

1. **Check `python-pptx` is available:**
   ```bash
   python -c "import pptx" 2>&1
   ```
   If it errors, tell the user: `pip install python-pptx` (or activate the virtual environment they already use for deck work).

2. **Run the script:**
   ```bash
   cd <seminar-slug> && python build_deck.py
   ```

3. **Confirm the output:** `ls <seminar-slug>.pptx` exists. Open it (or tell the user the path) to verify the deck rendered.

4. **Then move to Step 5 (Iterate).**

---

## When the user requests changes

The `build_deck.py` script is the source of truth. To revise:

1. Edit the relevant `slide_NN_*` function in `build_deck.py`
2. Update the matching section in `<seminar-slug>-transcript.md` if the script changed
3. Re-run `python build_deck.py` to regenerate the .pptx

Never edit the `.pptx` directly; changes will be lost on the next rebuild.
